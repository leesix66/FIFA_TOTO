# FIFA TOTO — 사내 FIFA 대회 승부 예측

토너먼트(최대 16팀) 대회의 승부를 직원들이 예측하고, 경기 결과에 따라 실시간으로 승률·순위를 보는 웹 서비스입니다.
Next.js(Vercel) + Supabase(PostgreSQL, Realtime).

- **참여자 페이지** `/` — 부서명·이름만으로 참여 (비밀번호 없이 **기기**로 본인 확인), 대진표에서 경기별 승리 팀(스코어 경기는 점수까지) 예측, 내 순위·승률, 전체 순위, 경기 결과
- **관리자 페이지** `/admin` — 관리자 코드로 입장. 팀 등록, 대진 배치, 경기별 예측 방식(승패/스코어), 3·4위전, 오픈·마감·공개, 결과 입력, 참여자 관리(기기 초기화·삭제·CSV)

## 처음 한 번만 하는 설정

### 1. Supabase 테이블 만들기
Supabase 대시보드 → **SQL Editor** → [`supabase/schema.sql`](supabase/schema.sql) 전체를 붙여넣고 **Run**.
(여러 번 실행해도 안전합니다. 테이블·순위 함수·보안 정책·실시간 설정까지 한 번에 만들어집니다.)

### 2. Vercel 환경변수
Vercel 프로젝트 → Settings → Environment Variables 에 아래를 등록한 뒤 **Redeploy** 하세요.
값은 Supabase 대시보드 → Project Settings → API 에 있습니다.

| 이름 | 값 | 비고 |
| --- | --- | --- |
| `SUPABASE_URL` | `https://xxxx.supabase.co` | Project URL |
| `SUPABASE_SERVICE_ROLE_KEY` | service_role (또는 secret) 키 | **서버 전용 — 절대 공개 금지** |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | anon (또는 publishable) 키 | 실시간 반영용 (없으면 12초 주기 자동 갱신) |
| `ADMIN_CODE` | 관리자 코드 | 관리자 페이지 입장 코드 |

> Vercel ↔ Supabase 연동(Integration)을 쓰고 있다면 Supabase 변수는 자동으로 들어가 있으니 `ADMIN_CODE` 만 추가하면 됩니다.
> 저장소가 공개(public)이므로 관리자 코드는 코드에 넣지 않고 환경변수로만 관리합니다.

## 운영 순서

1. **준비** — 관리자 페이지 `팀 · 대진` 탭에서 팀 등록 → 대진 배치(등록순/랜덤, 두 칸을 눌러 자리 교환) → 3·4위전 여부 → 경기별 예측 방식(승패/스코어)
2. **참여 오픈** — `운영` 탭에서 오픈. 이때부터 참여자가 등록·예측 (마감 전까지 수정 가능)
3. **참여 마감** — 등록·수정 잠금. `결과 입력` 탭에서 경기가 끝날 때마다 결과 입력 → 모든 화면의 순위가 즉시 갱신
4. **예측 공개** — 모든 참여자가 다른 사람의 예측과 경기별 예측 분포를 볼 수 있음

리허설을 해봤다면 `운영` 탭 하단의 **결과 전체 초기화 / 참여자 전체 삭제** 로 정리한 뒤 실제 대회를 시작하세요.

## 참여자 본인 확인 (기기 방식)

- 처음 접속한 브라우저에 무작위 기기 ID 를 만들어 저장하고(localStorage + 1년 쿠키), 서버에는 그 해시만 보관합니다.
- **한 기기 = 한 참여자.** 등록한 기기에서만 예측을 입력·수정할 수 있고, 다른 기기에서 같은 부서·이름으로는 들어갈 수 없습니다.
- 휴대폰 교체, 브라우저 데이터 삭제, 시크릿 모드 사용 등으로 기기를 잃으면 관리자가 `참여자` 탭에서 **기기 초기화** → 본인이 새 기기에서 같은 부서·이름으로 입장하면 기존 예측 그대로 연결됩니다.
- 다른 기기에서도 전체 순위·경기 결과는 누구나 볼 수 있습니다.

## 점수 규칙

- 승리 팀 적중 **1점**. 다음 라운드는 참여자가 예측한 팀으로 이어지는 브래킷 방식
- `스코어` 경기는 정확한 스코어(승리팀 득점:패배팀 득점)까지 맞히면 **+1점**
- 승률 = 적중 경기 ÷ 결과 확정 경기 (예측하지 않은 경기는 실패)
- 순위: 점수 → 적중 수, 같으면 공동 순위
- 팀 수가 2의 거듭제곱이 아니면 부전승이 자동 배치되며, 부전승 경기는 예측·결과 대상이 아닙니다
